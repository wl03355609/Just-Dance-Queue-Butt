## 0.10.0 — Fresh Coat

A full visual redesign of the desktop app and streamer dashboard, built with the Hallmark design system. No functional changes to queueing, pairing, or the bot — this is purely a look-and-feel refresh on top of [v0.9.1](https://github.com/wl03355609/Just-Dance-Queue-Butt/releases/tag/v0.9.1).

- **Redesigned settings window** — new color tokens, type scale, and a cleaner Workbench-style layout.
- **Polished streamer dashboard** — refreshed panels, spacing, and queue controls.
- **Consistent styling** across the desktop, overlay, and phone companion views.

The auto-updater will install this on launch as usual.
